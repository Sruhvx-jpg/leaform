# Project Rules

## Image & Logo Generation

- All logos, icons, and images generated (using Nano Banana or image generation tools) MUST be stored in the `etc/public/` directory.

## UI/UX & Color Palette Rules

- Always use the documented LeafForm White & Deep Forest Green design system specified in [DESIGN.md](file:///home/dron/Documents/programming/monoreop-tRPC/etc/doc/DESIGN.md).
- **Primary Dark Background**: Deep Forest Gradient `from-[#092218] via-[#0e2c20] to-[#081a13]` with ambient glow (`emerald-500/10`).
- **Brand Accent Greens**: `#134e3b`, `#0d5c41`, `#065f46`, and `#34d399` (emerald-400).
- **Light Contrast**: Pure White `#ffffff` with Slate 900 (`#0f172a`), Slate 600/500 text hierarchy and Slate 50 surfaces.
